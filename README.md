# ERP Paris

La Préfecture de police publie la liste des établissements parisiens recevant du public sous la forme d'un fichier CSV difficile à réutiliser.

API créée avec ADA (Python : FastAPI + PostgreSQL), documentée en OpenAPI : `/api/docs`. Fiche projet :
[PROJET.md](PROJET.md) ; consignes pour les agents de code : [AGENTS.md](AGENTS.md) ;
décisions : [docs/adr/](docs/adr/README.md).
