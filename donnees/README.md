# Données : ERP parisiens

`erp-paris.csv` : liste des établissements parisiens recevant du public (ERP) accessibles ou entrés dans la démarche de mise en accessibilité.

- **Source** : Préfecture de police de Paris, publiée par le ministère de l'Intérieur sur data.gouv.fr :
  [Liste des ERP parisiens conformes à la réglementation accessibilité ou entrés dans la démarche de mise en accessibilité](https://www.data.gouv.fr/datasets/liste-des-erp-parisiens-conformes-a-la-reglementation-accessibilite-ou-entres-dans-la-demarche-de-mise-en-accessibilite-1)
- **Licence** : Licence Ouverte 2.0
- **État du fichier** : brut, tel que publié. Lignes terminées par un point-virgule, espaces en tête, villes écrites de plusieurs façons, types secondaires multiples entre guillemets : c'est volontaire, le nettoyage est le travail de l'API.
- **Données réelles** : ce dépôt de démonstration contient volontairement des données publiques réelles.
